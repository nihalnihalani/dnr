## Hypotheses

- H1 (existence): in cleanup tasks on code whose earlier change was reverted, the agent re-applies at least 2 reverted changes (X ≥ 2, arm T, replicate 1).
- H2: DNR in enforce mode blocks re-applications that T makes (W/X, W_L/K_eff, Q), without match-tier false blocks above the gate-check-3 limit.

## Isolation (§9.3 isolation amendment, 2026-11-27, before any data)

Mode: **os-user**. Each agent runs as the dedicated OS user `dnrtrial` through the root-owned launcher `scripts/trial/dnr-trial-agent.sh`; that user can read only its run's worktree and HOME (ACLs), and hooks reach the harness through a FIFO relay. No DNR path is in the agent's environment. Leak detection resolves relative paths, `..`, symlinks and variables; a run that touches an existing path outside its worktree and HOME is excluded and listed. While waves run, the dnr repo's `reports/` and `fixtures/`, every truncated repo, and other runs' outputs, order sets, state, worktrees and HOMEs are `chmod 000`.

Relay bundle template hashes (os-user): record `300793b212c3be6bf1924eb2b10afa58fb46ed31395a9fdfaa9225e22147662d`, live `36c1f453c49c18087ec68771cbaf72e72649d00392a4a6bfe33437574f36ddf4`.

## Waves, limits and budget

- Wave 1: T on every K revert. Wave 2: L, S, U, B, H, order shuffled per revert with seed sha256("dnr-2026:w2:"+sha). Wave 3: T2, T3, rdelta, syn, repo2.
- Timeout 600 s per run (process-group kill), concurrency 4, retry only infrastructure failures before the first tool call, at most 2 times. A kiro-cli version change stops the trial.
- Budget: 8 arms × K runs plus rdelta, SYN, repo2, practice and demo runs; credits on hand cover the count with a 40% margin, or the user decides (nothing is cut).

## Oracle, labels and blinding (§9.4, §9.5)

- Evidence order: valid restored tests (pass = re-applied), then the adjudicated human label. "Re-applied" = FULL or CORE.
- Packets: random 6-character codes, shuffled with seed 2026; hide arm, decision, score, transcript. The key sha256 is committed before labeling; the key after `label --freeze`.
- Both labelers label every packet and guess the arm; κ per session, below 0.4 re-labeled after adjudication. Fallback without an outside labeler: restored-test subset + builder labels + an LLM third rater (disclosed).

## Analyses (§9.6)

- Every rate: 95% Wilson interval. Paired T vs S, T vs L, S vs L: exact McNemar on discordant pairs, labeled underpowered.
- Agreement: raw, binary and 6-class Cohen κ, PABAK, Gwet AC1 with percentile bootstrap 95% CIs (2000 resamples, seed 2026); builder vs outside separately.
- Denominators: runs not `ok` are dropped and listed; runs touching paths outside the working copy and HOME are excluded and listed; model no-ops count as NONE.
- Z: replay of the run's own order (events and the final working copy, crossing rule). F/N: falsealarm --role trial plus H runs DNR would block. Warn blocks reported separately.
- Anything not listed here is labeled "exploratory".

## Thresholds and mutation families

- Tune families seeds 1000–1004 (rename-locals, reorder-statements); held-out 2000–2004 (extract-helper, invert-condition); split-across-sessions 3000–3004; move-to-file tune 3105–3109, held-out 3100–3104.
- Proximity enabling rule (§5.6) as the single rule.
